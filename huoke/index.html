常见问题

开始之前,你可能想问

会不会封号?这是我们最关心的。

系统默认是"人工确认"模式,所有私信必须由你点过发送才走。采集任务有每日上限与最小间隔,不会像群发脚本那样高频触发风控。配合独立小号使用,长期跑下来风险可控——但任何自动化行为都不可能 100% 零风险,这点我们会讲清楚。

我没有技术背景,可以自己部署吗?

标准版包含 1 对 1 远程部署指导,通常 1 小时内完成。企业版我们直接上门或远程帮你装好,你自己只负责登录账号、添加关键词。

数据存哪里?会不会被第三方看到?

全部存于你自己的服务器或我们托管的独立服务器,数据库与登录 cookie 不外传,导出接口只对管理员账号开放。我们不存储你的账号密码。

可以做微信、淘宝这些平台吗?

目前覆盖社媒内容平台(小红书 / 抖音 / YouTube / B 站 / 知乎 / 微博 / 贴吧)。电商与即时通讯平台因 API 与合规限制不在本系统范围,可以走我们另一套企微 SCRM 方案,商务对接详谈。

可以试用吗?怎么收费?

支持 14 天免费试用,试用期内 1 个项目、单平台、每日 50 条线索。满意后升级标准版,一次性年付 ¥999。企业版按项目报价,通常 ¥1.5 万起。
